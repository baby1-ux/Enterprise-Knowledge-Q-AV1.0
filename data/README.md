# data 目录说明

`data/` 用于存放离线待解析的文档，同时作为文档解析入库的测试样本目录。

## 目录结构

```
data/
├── uploads/                     # 上传文件的实际存储位置（运行时自动创建，按 用户ID/知识库ID 分目录）
└── samples/                     # 演示与测试用样例文档
    ├── 产品保修政策.md
    ├── 售后服务规范.txt
    └── 使用说明.md
```

## 支持的文档类型

| 后缀 | 解析方式 |
| --- | --- |
| `.pdf` | pypdf 按页提取文本（扫描件请转图片） |
| `.pptx` | python-pptx 提取文本框与表格 |
| `.md` / `.markdown` | 按标题切分逻辑块 |
| `.txt` | 按空行切分段落 |
| `.docx` | python-docx 提取段落与表格 |
| `.png` / `.jpg` / `.jpeg` / `.bmp` / `.webp` | OCR（默认通义千问 qwen-vl-ocr） |

## 使用方式

1. 启动前后端，登录系统。
2. 进入「知识库」页面，新建知识库。
3. 进入该知识库的文档列表，点击「上传文档」，选择 `data/samples/` 下的样例文件。
4. 配置切块大小、重叠大小与检索方式（稠密 / 混合），提交后等待解析完成。
5. 回到「对话」页面，勾选该知识库后提问即可。
